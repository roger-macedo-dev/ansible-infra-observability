# Ansible Lab

Laboratório de automação de infraestrutura com Ansible.

## Ambiente
- **control** — nó de controle (Ansible)
- **node1** — nó gerenciado (Docker)

## Playbooks
- `playbook-docker.yml` — instala e habilita o Docker
- `playbook-nginx.yml` — sobe um container Nginx

## Stack
Ansible · Docker · AlmaLinux · VirtualBox
